# Desafio Giro Tech

Construção de métodos CRUD desenvolvido para o desafio Giro Tech.

## Funcionalidades

- Cadastro, leitura, edição e delete das entidades: Currency, Exchange Rate, Investments e Investors.

## Stack utilizada

**Back-end:** Java, SpringBoot, PostgreSql

## Rodando localmente

Clone o projeto

```bash
  git clone https://github.com/juliaknmelo/giro-teste-pratico-estagio
```

Abra a IDE de sua preferência e realize a instalação de dependências através dela. Ou, utilize o cmd dentro da pasta do
projeto e utilize o comando:

```bash
  mvn clean install
```

A partir da IDE de sua preferência dê start no projeto através do arquivo DesafioAplication (dentro da pasta:
src/main/java/com.girotech.desafio)

## Rodando os testes

Para testar a aplicação, após dar o start no projeto, abra o browser e utiliza a URL:

```bash
  http://localhost:8080/
```

Então é só testar a partir do swagger
